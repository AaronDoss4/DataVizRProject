# Instructions for Rendering

1. Download and unzip the Labor_Visualization zip file.
2. Open the Labor_Visualization folder.
3. Open the .Rproj file in RStudio.
4. Open the Quarto .qmd file.
5. Install the required R packages if they are not already installed:
install.packages("readxl")
install.packages("tidyverse")
install.packages("treemapify")
6. Click the Render button at the top of RStudio.
7. The completed HTML report will be generated in the project folder.
